SplatWorks Desktop

PDFsplat and CipherSplat run locally. The editor, PDF libraries, OCR engines, English and Spanish models, and encryption tools are included.

Your files

Use Open file or drag files into a tool. Saving opens a native destination picker. Switching tools keeps each workspace open. Closing the application discards unsaved work.

CipherSplat restores folders inside a new folder at your chosen destination. Existing folders are never overlaid. Passwords cannot be recovered; test an encrypted copy before deleting an original.

Features to review

PDF text replacement and visual covers preserve underlying content. They are not secure redaction. OCR requires review and does not create a tagged, accessible PDF.

Camera capture depends on platform permissions. Tab and window capture is available only when the embedded webview supports screen sharing. Use the browser edition for workflows that need browser tab capture. WebDeck exports open in your browser for presentation and printing.

About this edition

This is a Go desktop shell using Wails and the existing local web tools. Native saves are streamed in chunks. The tools retain their existing PDF and browser memory limits.

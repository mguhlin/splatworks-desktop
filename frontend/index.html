SplatWorks Desktop

ListSplat, GridSplat, WriteSplat, ShowSplat, LayoutSplat, PlanSplat, PDFsplat, CipherSplat, GIFsplat, QRSplat, ImageSplat, AudioSplat, VideoSplat, and MediaSplat run locally. Choose an app on Home or from the Apps menu. The editors, import libraries, PDF and OCR engines, English and Spanish OCR models, and encryption tools are included.

Your files

Use Open file or drag files into a tool. Ctrl/Command+S saves editable work; other exports keep the original project marked as unsaved. Google Drive and Calendar connections are available in the browser editions. Saving opens a native destination picker. Switching tools keeps each workspace open. The app warns before discarding unsaved work and waits for active operations before closing. It does not create automatic recovery copies.

GridSplat project files keep worksheet data, formulas and cell formatting. Export charts and picture graphs as images to keep their appearance.

CipherSplat restores folders inside a new folder at your chosen destination. Existing folders are never overlaid. Passwords cannot be recovered; test an encrypted copy before deleting an original.

Features to review

PDF text replacement and visual covers preserve underlying content. They are not secure redaction. OCR requires review and does not create a tagged, accessible PDF.

Live camera and screen capture are available in the browser edition. In this desktop edition, import existing photos for scanning. WebDeck exports open in your browser for presentation and printing.

AudioSplat and VideoSplat save portable editable projects as well as media exports. MediaSplat trims, splits, joins, and captions media; save its output files before closing. Media imports are limited to 256 MiB in total in MediaSplat. ImageSplat includes the Fast background-removal model. Speech models are optional downloads: enable online connections in Settings to obtain one before using it offline.

About this edition

This is a Go desktop shell using Wails and the existing local web tools. Native saves are streamed in chunks. The tools retain their existing PDF and browser memory limits.

The shell is AGPL-3.0-or-later. Office apps are GPL-3.0-only. Bundled dependencies retain their licenses. Source, licenses, and downloads · SplatWorks website. Website links open in your browser and require an internet connection.

Online features

Off by default. Bundled features work offline. Turn this on to use optional model downloads, configured QR services or online image backgrounds where available in this app. Photo processing stays on this device.

Turning this off stops active external requests. Service credentials are kept in memory. Application updates are downloaded and installed manually.

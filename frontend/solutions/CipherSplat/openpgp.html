    Browser help

    CipherSplat 1.1.0 · Choose a question below, or return to the password workspace or OpenPGP workspace.

    How does CipherSplat protect my data?
    • AES-256-GCM encrypts password-protected files and text and checks for changes when unlocking them.
    • Argon2id strengthens the key derived from your password.
    • Files, passwords and keys are processed on your device.

    Browser FAQs

    What do I do first?
    • Set a strong password in Step 1.
    • Add files or a folder, or type/paste text in Step 2. Encrypted content is detected automatically.
    • Find the saved file or copy your text result in Step 3.
    Where does my result go?
    • Encrypted files download automatically as .csplat. Your browser controls where they save.
    • Some browsers ask for a save location before processing. Other browsers use their normal download settings.
    • The browser cannot automatically save beside your original file. The desktop apps use a native destination dialog.
    What happens to a folder?
    • Files and folders are ZIP-compressed before password encryption. Unlocking unzips them automatically.
    • A single restored file downloads directly. For folders, supported browsers can write a new folder; others offer individual file saves or an optional ZIP.
    • Folder picking varies by phone and browser. Empty folders may not be included.
    Can I copy encrypted text?
    • Yes. Encrypted text appears in a result box with a Copy button and is saved as a .csplat file.
    • Paste the encrypted text with the same password to unlock it. If copying is blocked, select the text and copy it manually.
    What if I forget the password or a file will not open?
    • Passwords cannot be recovered. Save yours securely.
    • Check the password and make sure the encrypted file is complete. Changed or incomplete files fail authentication.
    • OpenPGP messages need the key workspace. Packages using unsupported algorithms need the application that created them.
    Are originals shredded or replaced?
    • No. This browser tool leaves originals untouched.
    • CipherSplat desktop also keeps originals. Saved files and restored folders use destinations you choose.
    What stays on my device?
    • Your files, text, passwords and keys are processed locally. CipherSplat does not upload encryption inputs or store your keys. The ecosystem privacy controls explain website requests and preferences.
    • When you open this tool online, the website receives normal requests for the page and its bundled assets.
    • Your browser, operating system, extensions, downloads, clipboard, device backups, and shared-device access remain under their respective controls.
    What does Clear workspace do?
    • It releases the active inputs and results. The workspace also clears after ten idle minutes.
    • It does not delete downloads, clipboard contents or backups. Keep the tab open while processing, especially on phones.

    OpenPGP FAQs

    Which key should I use?
    • To encrypt: use the recipient’s public key. Compare its fingerprint with them through another trusted channel.
    • To unlock: use the private key matching the public key that encrypted the message.
    • If the private key is protected, enter its private-key passphrase too.
    How do I add my existing key?
    • Export the key from your OpenPGP key manager.
    • In Step 1, paste the complete public/private key block or choose Import key file for its .asc/.pgp export.
    • Check the displayed fingerprint, then add your file or text in Step 2.
    • Import a key file or paste its contents; a key-server web address will not work here.
    Can I encrypt folders or several files?
    • This workspace handles one file or text message at a time. ZIP a folder or group of files first.
    • Use the password workspace for automatic file/folder packaging and restoration.
    Where is my result?
    • Encrypted files download as .csplat; your browser controls the save location.
    • Encrypted and decrypted text appear on screen with a Copy button.
    • These are standard OpenPGP messages. Other OpenPGP tools may expect a .gpg or .asc filename ending.
    Are my keys saved or linked to an account?
    • No. Keys are used in this tab and clear after success, Clear or inactivity. Import or paste them again for another operation.
    • CipherSplat does not create key pairs, fetch keys from servers or link to an account.
    • Keep your private key private and backed up. CipherSplat cannot recover a lost key or passphrase.
    Does my data leave my device?
    • Files, text, keys and passphrases are processed locally in this tab.
    • The website receives normal page and asset requests.
    • Your browser, downloads, clipboard, backups and extensions remain under your device’s controls.
    Can I use this key in the desktop app?
    • OpenPGP is available in the browser, standalone CipherSplat, and the PDF/Cipher desktop suite. Use the same exported keys in each edition.
    • For a password-protected .csplat file, open the password workspace.
